# 🚀🔐 Cerberus – Secure Ingress Proxy with Traefik, Docker & Proxmox Automation![Stars](https://img.shields.io/github/stars/xgueret/proxmox-vm-dsnzilla?style=social)![Last Commit](https://img.shields.io/github/last-commit/xgueret/proxmox-vm-dnszilla)![Status](https://img.shields.io/badge/Status-Active-brightgreen)

This project automates the deployment of a standalone Traefik reverse proxy inside a dedicated VM using Terraform (Proxmox) and Ansible. Docker is used to simplify configuration, isolation, and maintenance.
